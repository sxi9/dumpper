# Dumper (browser extension) — universal leak-site dumper

Opens a side panel on any leak site you have loaded (CAPTCHA solved, cards visible), finds the victim
list, groups it by publish date, lets you tick victims (or a whole date), and downloads ONE JSON dump
to hand to Claude. It never reloads or navigates the page.

## How victims are found (in this order, "Source" line in the panel says which one won)
1. **Data adapters** — sites that keep the list in JavaScript: The Gentlemen (`companies`), any global
   or `<script>` JSON array of victim-like objects (Leaknet `INIT_DATA`).
1b. **JSON feeds** — leak sites that *are* a JSON API (the page is raw JSON, or the SPA holds the feed in
   a global): INC Ransom (`payload.announcements[].company`), RansomHouse (`data[]`), Akira (`objects[]`,
   terminal markup unwrapped), plus a generic nested walk for any other JSON feed whose victim name sits
   under a child object. Ported from leakwatch `p_inc_json` / `p_ransomhouse_json` / `p_akira_json`. Open
   the API URL directly (or the SPA), and the panel turns the JSON into the same victim cards.
2. **Site profiles** — 101 templates ported from [sxi9/leakwatch](https://github.com/sxi9/leakwatch)
   (`leakwatch/parsers/profiles.py`): a fingerprint selector identifies the template, item / title /
   link / date / description selectors read each victim. `data.js` is generated by
   `scripts/build-dumper-data.py`; it also carries the onion → group map from `seeds/sites.json`, so
   the group name is pre-filled.
3. **Generic cards** — repeated containers with post/card/item-like class names, table rows, headings
   (ported from leakwatch `parse_auto` with its noise rules).
4. **Visual structure** (2.1) — repeated blocks of the same rendered shape, whatever their class
   names (sites with obfuscated or meaningless classes).
5. **Pick a card** (2.1) — click the button, then click one victim card on the page; every block
   built the same way becomes the list. Remembered per site.
6. **Custom selectors** — pick "custom selectors" in the mode box, type an item selector (one per
   victim) and optional title / link / date / description selectors, Apply. Saved per site.
7. **AI assist** (2.1, optional, Gemini) — **Scan page (AI)** sends the trimmed page HTML to Gemini
   and gets a selector profile back; **Scan card (AI)** does the same from the card you picked;
   **Fix (AI)** sends the current wrong titles plus the matched HTML for a corrected profile. The
   extension tests the answer live (count + first titles) before you **Save profile**; a saved
   profile wins in auto mode on that site from then on, and **Copy profile JSON** exports it in the
   leakwatch custom-profile format. Nothing is sent unless you press one of these buttons.
8. **Always open + auto AI** (2.1.4) — on `.onion` pages the panel opens at once and fills as detection
   runs; if nothing is found within 15 s (or after a toolbar click on an empty page) and Gemini keys are
   configured, **Scan page (AI)** runs by itself once per site ("auto AI" toggle in the AI row).
8b. **Embedded frames and shadow DOM** (2.1.4) — lists inside an `<iframe>` are detected in the frame
   and shown in the top panel; open shadow roots are searched too; pages that build their list late are
   re-scanned for 90 s. **Diagnose** downloads a small report of what the page looks like to the detector
   — send it to Claude when a site still yields nothing.
9. **Dump whole page** (2.1) — when nothing lists, dump the entire page anyway (visible text in
   order, HTML, CSS, images, links, and the linked same-site pages) so Claude can extract the
   victims offline.

### AI setup (Options page)
Right-click the Dumper icon → Options (or `chrome://extensions` → Details → Extension options).
Paste one or more **Gemini API keys, one per line**: they are used **round robin**; a key that
answers with a quota / rate-limit error is parked for 10 minutes and the next one is used, an
invalid key is skipped; "Un-park / re-enable all keys" resets that. Set the model (default
`gemini-2.5-flash`) and tick the consent box. Keys live in the extension's own storage and are sent
only to `generativelanguage.googleapis.com` from the extension background — the leak site's page
never sees them. What is sent: the page's HTML with scripts, styles, images and inline data removed,
capped at 60 KB (25 KB for card / fix scans).

The mode box also lets you force a specific profile or the generic pass; **Rescan** re-runs detection
after the page loads more cards. Hovering a victim in the panel outlines its card on the page. If nothing
is found after 15 s the panel opens anyway so Pick / AI / whole-page are reachable.

## What a dump holds (per victim)
title · url · publishedDate (+ raw dateText) · timerLine (exactly what the card shows, label and value
joined) · description · leakText (card text in visual order = the Code block) · links · mediaLinks ·
iocs (domains + ZoomInfo profiles) · images / logoUrl (+ `assets` base64) · cardHtml · cardPng (real in
Chrome; skipped in Tor Browser, where canvas reads are noise) · detail (the victim's own page: text,
links, images — on by default, same-origin only). Plus `pageCss` (the site's stylesheets) so Claude
or the Intake page can re-render any card pixel-faithfully.

## Where it works
- `.onion` sites: the extension loads by itself and the panel opens when victims are found (or after 15 s).
- Any other site (clearnet mirrors, test pages): click the **Dumper toolbar icon** — it injects the panel
  on demand into that tab. Pin the icon so it is always visible.
- Chrome asks once at install for "read and change data on all websites": that is what lets the icon
  work on any site. **Tor Browser / Firefox** do not grant it automatically: open `about:addons` →
  Dumper → **Permissions** and switch on *Access your data for all websites* (and the .onion one),
  otherwise neither the automatic panel nor the icon can run on the page.

## Options page (API keys)
Panel → **Options** button, or: Chrome `chrome://extensions` → Dumper → Details → *Extension options*
(also right-click the icon → Options); Tor Browser / Firefox `about:addons` → Dumper → *Preferences*.
If the entry is missing, the old version is still loaded: remove the extension and load the new folder.

## Install (once)
Chrome / Brave / Edge: `chrome://extensions` → Developer mode → Load unpacked → this folder. Pin it from
the puzzle-piece menu; the toolbar icon opens/closes the panel.
Tor Browser / Firefox: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → `manifest.json`
(temporary add-ons are removed when the browser closes).

## Use
1. Open the leak site, solve the CAPTCHA, wait for the cards. The **Dumper** panel opens by itself when it
   finds victims (or click the icon / the floating button).
2. Check the Source line and the count. If it is wrong, change the mode box or type custom selectors.
3. Filter, tick, **Dump selected** → `<group>-dump-<date>-<n>.json` in Downloads → send to Claude or
   drop into the Needle Intake page. Dumped victims get a `dumped <date>` badge; "only not yet dumped"
   shows just the new ones next time.

## Updating the site tables
Pull leakwatch, then `python3 scripts/build-dumper-data.py /path/to/leakwatch` and reload the extension.
